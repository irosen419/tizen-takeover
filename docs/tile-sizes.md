# Home Hub: what shows at each tile size

This mirrors `SIZE_MATRIX` in the Layout Studio artifact (English text only; the artifact also has Spanish). Checked against the TV code in PR 17 (v0.12.2) (`app/hub.js` `sizeOf`/`applySize`, `app/style.css` tile sizes, `app/widgets/*.js` and `*.css`).

## Rules

- The grid is 12 columns by 6 rows. A tile's size in cells picks how it draws.
- **Tier (height):** strip = 1 row, standard = 2 rows, tall = 3 or more rows.
- **Width:** narrow = 1–2 columns, standard = 3–5 columns, wide = 6 or more. A 1-column tile also gets `tile-w1`: no words, only the one number, time or icon that fits.
- **Clicked** opens the panel (46 × 26 rem on an 80 × 45 rem screen, about a third of the screen); its Full screen button fills the screen. A widget with `expandable: false` (the Clock) does not open.
